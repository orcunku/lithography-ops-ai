# Overlay calibration procedure

Subsystem: reticle stage
Document ID: KB-OVL-03

Standard overlay recalibration: place the calibration reticle, run the mark detection routine across all field points, and let the system compute the correction grid. Verify the reported model error is within specification before releasing the tool. If the routine fails mark detection repeatedly, the illumination on the alignment sensor may be low; clean the sensor window and retry before replacing hardware.

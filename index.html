What it does

Six jobs, one operator workflow

The system turns noisy machine telemetry into decisions an engineer can act on — always keeping a person in control.

01

Detects anomalies early

An Isolation Forest scores machine health from nine sensor signals and flags abnormal behaviour before it trips hard alarms.

02

Predicts failure & RUL

Gradient-boosted models estimate near-term failure risk and how many minutes of useful life remain.

03

Triages incidents

A six-agent team ranks urgency and names the likely subsystem, always showing the sensor evidence behind it.

04

Retrieves knowledge (RAG)

Semantic search over a maintenance knowledge base finds the right procedure from plain-language symptoms.

05

Writes cited reports

A small local language model drafts a fluent shift-handover summary, grounded in the evidence and cited to source docs.

06

Keeps humans in control

Every recommendation is read-only until a person approves it, and every action is written to an append-only audit trail.

The pipeline

From raw sensors to an approved decision

Each stage was built, then measured — not assumed.

01

Synthetic data + ML models

Three simulated machines with labelled anomaly, failure and remaining-useful-life data.

scikit-learn · pandas · NumPy
02

Semantic retrieval (RAG)

Maintenance docs embedded into a vector store; the right procedure is found by meaning, not keywords. Measured at 0.92 Hit@1.

sentence-transformers · FAISS
03

Grounded generation

A local language model turns evidence + retrieved procedures into a cited report, with checks against inventing facts.

Hugging Face Transformers
04

Evaluation harness

Retrieval metrics (Hit@1, MRR) on a labelled set, plus a groundedness check that flags fabricated citations or invented numbers.

pytest · custom metrics
05

Application & governance

A REST API and control-room dashboard, an MCP tool layer for read-only data access, and a full audit trail.

FastAPI · Streamlit · MCP · SQLite
